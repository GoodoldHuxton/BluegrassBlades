# Bluegrass Blades [B42]

A Project Zomboid Build 42 mod that adds 38 knife variants set in 1993 Kentucky: Bowie, Fillet, Folder, Trapper and Balisong. Each knife has a grade (Military, Sporting, Handmade, Knockoff), a handle and a blade finish. It uses the vanilla models with new textures, and the stats stay close to vanilla.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3820010936
- Tested on Build 42.21, single player. Multiplayer has not been tested yet.
- Support: https://patreon.com/GoodoldHuxton (all content is free; there is no paid or early access content)
